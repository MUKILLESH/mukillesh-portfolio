# Remotion Video Skill

Use Remotion for programmatically generated videos, product demos, social clips, explainers, logo animations, and motion-graphics compositions.

## Use Remotion for
- Product demo videos
- Website showcase videos
- Social-media clips
- Animated explainers
- Logo reveals
- Data-driven motion graphics
- Reusable video templates
- Automatically generated variations

## Rules
- Build videos from reusable React components.
- Use Remotion's composition and sequencing model for timing.
- Keep animation deterministic and frame-accurate.
- Prefer interpolation and spring-based motion where appropriate.
- Keep text readable and inside safe margins.
- Design for the target aspect ratio and resolution.
- Avoid browser-only APIs inside render-critical code unless properly handled.
- Keep assets local/reproducible when possible.
- Separate content/data from presentation so videos can be generated from different inputs.
- Optimize expensive effects for rendering performance.
- Remember: Remotion is for video generation/rendering; use Motion/GSAP for ordinary website UI animation.
